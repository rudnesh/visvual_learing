Reinforcement Learning

What is Reinforcement Learning?

Reinforcement Learning (RL) is a machine learning paradigm where an agent learns to make decisions by interacting with an environment. The agent receives rewards or penalties for its actions and learns to maximize cumulative reward over time.

The agent chooses an action at, the environment returns a new state st+1 and reward rt. The goal is to maximize the expected cumulative (discounted) reward.

Key Concepts

🎯

Policy (π)

Strategy that maps states to actions — can be deterministic or stochastic.

💎

Value Function

Expected discounted return from a state (V) or state-action pair (Q).

⚖️

Exploration vs Exploitation

Balance between trying new actions and leveraging known rewarding ones.

📦

MDP

Markov Decision Process: (S, A, P, R, γ) — the formal RL framework.

Value-Based Methods

Core idea: Learn the optimal value function (Q-function or V-function). The policy is implicitly derived from the value function — choose the action with the highest Q-value.

Key Equation (Bellman Optimality):
Q*(s, a) = 𝔼[r + γ · maxa' Q*(s', a')]

Q-Learning Workflow

Step through the algorithm:

Q-Learning is an off-policy TD control algorithm. The agent observes the current state, selects an action (often ε-greedy), receives a reward and next state, then updates the Q-table using the Bellman equation.

Observe: The agent starts in state s. In early episodes, the Q-table is initialized to zeros (or small random values).

ε-greedy action selection: With probability ε, pick a random action (explore). With probability 1−ε, pick a = argmax Q(s, a) (exploit).

Experience: The environment transitions to s' and provides reward r. This transition (s, a, r, s') is the raw learning signal.

Update: Q(s,a) ← Q(s,a) + α[r + γ·maxa'Q(s',a') − Q(s,a)]. The agent bootstraps from its own estimate of future returns — this is temporal difference learning.

Deep Q-Networks (DQN)

When the state space is too large for a Q-table (e.g., raw pixels from a game), a neural network approximates the Q-function:

  • Experience Replay: stores transitions (s, a, r, s') in a buffer and trains on random minibatches to break correlation
  • Target Network: a separate frozen Q-network is used to compute TD targets, updated periodically for stability
  • Reward Clipping: gradients are stabilized by clipping reward values

Policy-Based Methods

Core idea: Directly learn a parameterized policy πθ(a|s) without storing value estimates. The policy is optimized via policy gradient — gradient ascent on expected return.

Policy Gradient (REINFORCE):
∇J(θ) = 𝔼[ Σ ∇log πθ(at|st) · Gt ]

where Gt is the total discounted return from time t. Intuitively, actions that led to higher returns get higher probability.

How Policy Gradients Work

t (discounted sum of rewards) Log-Prob × Gt = gradient θ ← θ + α∇J Collect trajectories → estimate returns → update policy → repeat

Popular Policy-Based Algorithms

  • REINFORCE (Monte Carlo Policy Gradient): uses full return Gt from complete episodes — high variance
  • PPO (Proximal Policy Optimization): clips policy updates to prevent destructive large changes; stable and widely used
  • TRPO (Trust Region Policy Optimization): enforces a KL-divergence constraint on policy updates for monotonic improvement

Actor-Critic Methods

Core idea: Combine the best of both worlds — use a policy network (actor) to decide actions and a value network (critic) to evaluate them. The critic reduces variance by providing a baseline for the policy gradient.

Actor-Critic Architecture

Information flow:

θ) outputs action distribution Critic (Vφ) outputs state value V(s) Action a ~ πθ(·|s) Baseline Vφ(s) Advantage: A = reward + γV(s') − V(s)

Actor-Critic methods have two components: the actor (policy network) selects actions, and the critic (value network) evaluates them. The critic's value estimate serves as a baseline, reducing the variance of the policy gradient.

Forward pass: Given state s, the actor produces an action distribution π(a|s) and samples an action. The critic produces the state value V(s).

Training: The advantage A = r + γV(s') − V(s) is computed. The actor is updated to increase log-probability of actions with positive advantage. The critic is updated to minimize TD error.

Popular Actor-Critic Algorithms

  • A2C (Advantage Actor-Critic): synchronous version of A3C; computes advantage A = Q − V or TD residual
  • A3C (Asynchronous Advantage Actor-Critic): multiple parallel workers each interacting with their own copy of the environment, asynchronously updating a shared model
  • SAC (Soft Actor-Critic): maximizes a trade-off between expected return and entropy (exploration); state-of-the-art in continuous control
SAC objective: J(π) = Σ 𝔼[r(s,a) + α · ℋ(π(·|s))] — maximizes both reward and policy entropy.

Model-Based Reinforcement Learning

Core idea: Learn a model of the environment's dynamics — a function that predicts the next state and reward given the current state and action — then use that model for planning or to augment model-free learning.

World Model: st+1, rt ≈ f(st, at)

Dyna Architecture

Real experience trains the world model → simulated experience trains the policy → more real experience is collected → repeat.

Model-Based Algorithms

  • Dyna-Q: classic architecture that interleaves real experience with simulated rollouts from the learned model to accelerate Q-learning
  • Monte Carlo Tree Search (MCTS): uses the model to simulate many game trajectories and selects the best action by tree search (used in AlphaGo/AlphaZero)
  • MuZero: learns a model that predicts only the quantities relevant for planning (value, policy, reward) without needing the true environment dynamics
  • Dreamer: learns a latent world model from pixels and trains an actor-critic entirely within "dreams" (imagined trajectories)

When to Use Which?

Value-Based

Discrete action spaces, deterministic environments, when Q-values are easy to represent (e.g., Atari games with DQN).

Policy-Based

Continuous action spaces (robotics, control), when the optimal policy is stochastic, or when you need stable convergence guarantees.

Actor-Critic

Best general-purpose choice. SAC for continuous control, A2C/P PO for discrete tasks. Balances variance, speed, and sample efficiency.

Model-Based

When sample efficiency is critical (robotics, real-world systems), or when a model can be learned (games with known rules, simulated environments).
